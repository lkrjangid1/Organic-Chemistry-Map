## What is functional group priority?

When a compound contains **more than one functional group**, IUPAC rules pick one of them as the **principal characteristic group**. That group decides the **suffix** of the name and gets the **lowest possible locant**; every other group is cited as a **prefix**. The choice is made from a fixed **order of priority (seniority)**, which is the table students must memorise.

<KeyPoint title="Priority order (highest first)">
**–COOH > –SO₃H > –CO–O–CO– > –COOR > –COX > –CONH₂ > –C≡N > –N≡C > –CHO > >C=O > –OH > –SH > –NH₂ > C=C, C≡C**

Always prefix only: –X (halo), –NO₂ (nitro), –OR (alkoxy), –R (alkyl), –C₆H₅ (phenyl).
</KeyPoint>

## Prefix and suffix table

| Priority | Group | Class | Prefix | Suffix |
|---|---|---|---|---|
| 1 | –COOH | carboxylic acid | carboxy | -oic acid / -carboxylic acid |
| 2 | –SO₃H | sulphonic acid | sulfo (sulpho) | -sulfonic acid |
| 3 | –CO–O–CO– | acid anhydride | rarely used | -oic anhydride / -carboxylic anhydride |
| 4 | –COOR | ester | alkoxycarbonyl | alkyl -oate / alkyl -carboxylate |
| 5 | –COX | acyl halide | halocarbonyl | -oyl halide / -carbonyl halide |
| 6 | –CONH₂ | amide | carbamoyl | -amide / -carboxamide |
| 7 | –C≡N | nitrile | cyano | -nitrile / -carbonitrile |
| 8 | –N≡C | isocyanide (isonitrile) | isocyano | isocyanide |
| 9 | –CHO | aldehyde | formyl (oxo when the C is in the chain) | -al / -carbaldehyde |
| 10 | >C=O | ketone | oxo | -one |
| 11 | –OH | alcohol | hydroxy | -ol |
| 12 | –SH | thiol | sulfanyl (older: mercapto) | -thiol |
| 13 | –NH₂ | amine | amino | -amine |

**Notes on the table**

- The first suffix in each pair (-oic acid, -al, -nitrile, -amide) counts the carbon of the group as part of the main chain. The second (-carboxylic acid, -carbaldehyde, -carbonitrile, -carboxamide) is used when that carbon is outside the parent, typically on a ring.
- An ester group pointing the other way, R–CO–O– attached to the chain, is named with an **acyloxy** prefix such as acetyloxy.
- "Carbylamine" for an isocyanide is an old name that clashes with systematic naming, because the group is not an amine. Use isocyano as the prefix.
- Double and triple bonds take only the endings -ene and -yne, which combine with any suffix (prop-2-enal, but-3-yn-1-ol).

## How to name a polyfunctional compound

1. Find the **principal group** using the priority order.
2. Choose the **longest chain (or ring) that contains it** and as many multiple bonds as possible.
3. Number so the principal group gets the **lowest locant**. For –COOH, –CHO, –CN and –CONH₂ in the chain this carbon is C-1.
4. Name all other groups as **prefixes in alphabetical order**, each with its locant.
5. Add -ene/-yne for multiple bonds, then the suffix.

## Solved examples

| Structure | Principal group | IUPAC name |
|---|---|---|
| HOCH₂CH₂COOH | –COOH | 3-hydroxypropanoic acid |
| OHC–CH₂CH₂–CO–CH₃ | –CHO | 4-oxopentanal |
| CH₃COCH₂CH(OH)CH₃ | >C=O | 4-hydroxypentan-2-one |
| NC–CH₂CH₂–COOH | –COOH | 3-cyanopropanoic acid |
| H₂N–CH₂CH₂–OH | –OH | 2-aminoethan-1-ol |
| CH₂=CH–CHO | –CHO | prop-2-enal |
| ClCH₂CH₂CH₂OH | –OH | 3-chloropropan-1-ol |
| CH₃O–CO–CH₂CH₂–COOH | –COOH | 4-methoxy-4-oxobutanoic acid |
| HO–C₆H₁₀–COOH (1,4 on a cyclohexane ring) | –COOH | 4-hydroxycyclohexane-1-carboxylic acid |

**Worked reasoning for 4-oxopentanal.** The molecule has an aldehyde and a ketone. The aldehyde ranks higher, so the name ends in -al and the CHO carbon is C-1. Counting along the five-carbon chain puts the ketone C=O at C-4, cited as the prefix oxo.

**Worked reasoning for 2-aminoethan-1-ol.** Alcohol outranks amine, so the suffix is -ol on C-1 and the –NH₂ on C-2 becomes amino.

<ExamTip title="Common mistakes">
- Writing "keto" or "mercapto" in a full IUPAC answer: use **oxo** and **sulfanyl**.
- Giving a halogen or nitro group the suffix: they are always prefixes, so ClCH₂CH₂OH is 2-chloroethan-1-ol.
- Forgetting that the C of –COOH, –CHO and –CN is C-1 in an open chain, so it gets no locant in the name (propanoic acid, not propan-1-oic acid).
- Numbering to give a double bond or a halogen the lowest locant ahead of the principal group.
</ExamTip>
